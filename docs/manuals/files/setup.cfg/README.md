## 파일 역할

ROS 실행 스크립트의 설치 위치를 지정합니다. 원본은 [setup.cfg](../../../../setup.cfg)입니다.

## 사용 순서

colcon 빌드 시 자동으로 읽히므로 보통 수정하지 않습니다.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

develop/install의 script 경로를 lib/pinky_line_alignment로 설정합니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

이 파일은 코드 스타일 설정이 아닙니다.
