## 파일 역할

프로젝트의 실행 순서와 실물 검증 한계를 안내합니다. 원본은 [README.md](../../../../README.md)입니다.

## 사용 순서

처음에는 오프라인 검증을 하고, 이후 ROS 빌드와 모터 OFF 센서 확인으로 진행하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

Python 3.12 및 ROS 2 Jazzy 환경이 기준입니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

합성 테스트 결과를 실물 성능으로 해석하지 마세요.
