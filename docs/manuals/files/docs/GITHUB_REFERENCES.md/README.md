## 파일 역할

구현 때 참고했다고 기록된 외부 출처와 활용 이유를 정리합니다. 원본은 [docs/GITHUB_REFERENCES.md](../../../../GITHUB_REFERENCES.md)입니다.

## 사용 순서

링크별 사용 범위를 확인하고 실물 설치본의 버전·SHA는 별도 기록하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

공식 PinkLAB 자료와 OpenCV 문서, 구조 참고 저장소를 구분합니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

이전 작성 시점의 기록입니다. 현재 push 상태는 실제 Git 기록으로 확인하세요.
