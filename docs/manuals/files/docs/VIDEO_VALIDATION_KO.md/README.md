## 역할

재생·합성 명령 검증의 전체 실행 순서와 결과 해석을 안내합니다. [원본 파일](../../../../VIDEO_VALIDATION_KO.md)을 확인하세요.

## 사용 순서

설치→합성 예제→실제 저장 영상→결과 확인→모터 OFF 현장 확인 순서로 읽습니다.

명령은 저장소 루트의 오프라인 가상환경에서 실행합니다. ROS 노드는 별도의 시스템 Jazzy 환경을 사용합니다.

## 입력과 출력

CLI, 설정, 출력 트리, 유효 관측과 정확도의 차이를 설명합니다.

## 완료 기준과 주의사항

실물 주행은 별도 검증이며 Notion 자동 동기화 기능은 없습니다.
