## 파일 역할

이전 Notion 구현 기록의 저장소 사본을 제공합니다. 원본은 [docs/NOTION_IMPLEMENTATION.md](../../../../NOTION_IMPLEMENTATION.md)입니다.

## 사용 순서

개발 기록 참고용으로 읽고 최신 검증은 현재 실행 결과를 사용하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

실측·mux·IR·실물 검증 등 미완료 항목이 있습니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

이 파일을 수정해도 Notion에 자동 반영되지 않습니다.
