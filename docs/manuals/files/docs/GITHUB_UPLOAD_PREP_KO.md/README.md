## 파일 역할

초기 개인 저장소 업로드 준비 과정을 보관합니다. 원본은 [docs/GITHUB_UPLOAD_PREP_KO.md](../../../../GITHUB_UPLOAD_PREP_KO.md)입니다.

## 사용 순서

과거 제안 문서로 읽고 현재는 seljb/pinky_pro_line_tracer의 기능 브랜치를 사용하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

현재 브랜치는 feat/line-alignment입니다. main 직접 push 대신 PR과 리뷰를 사용합니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

문서의 예전 저장소명과 git init/push 예시는 현재 작업 명령이 아닙니다.
