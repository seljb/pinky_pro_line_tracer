## 파일 역할

실물 연결 전 센서·보정·안전 확인 순서를 제공합니다. 원본은 [docs/ROBOT_TEST_CHECKLIST_KO.md](../../../../ROBOT_TEST_CHECKLIST_KO.md)입니다.

## 사용 순서

내일 체크리스트와 함께 모터 OFF 항목부터 수행하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

장치 확인→보정→인식 진단→조건부 주행→실험 기록 순서입니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

센서 확인 완료만으로 주행 승인이 되지 않습니다. 외부 mux와 물리 비상정지는 별도입니다.
