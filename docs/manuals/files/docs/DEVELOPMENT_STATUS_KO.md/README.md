## 사용 순서

현재 실행 결과와 문서의 범위 표를 대조합니다.

명령은 저장소 루트의 오프라인 가상환경에서 실행합니다. ROS 노드는 별도의 시스템 Jazzy 환경을 사용합니다.

## 입력과 출력

시험·재생·합성·설치 검증과 미실시 항목을 구분합니다.
