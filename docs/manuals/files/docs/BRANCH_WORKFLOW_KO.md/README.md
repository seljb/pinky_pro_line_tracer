## 역할

기존 브랜치를 보존하면서 기능 브랜치를 통합하는 방법을 안내합니다. [원본 파일](../../../../BRANCH_WORKFLOW_KO.md)을 확인하세요.

## 사용 순서

새 작업은 feat/video-validation에서 받고 기능별 branch와 PR base를 확인합니다.

명령은 저장소 루트의 오프라인 가상환경에서 실행합니다. ROS 노드는 별도의 시스템 Jazzy 환경을 사용합니다.

## 입력과 출력

영문 Conventional Commits, no-ff 개발 통합, 팀 리뷰 후 최종 반영을 구분합니다.

## 완료 기준과 주의사항

개발 통합은 타인의 승인이나 main 병합을 대신하지 않습니다. 강제 push하지 않습니다.
