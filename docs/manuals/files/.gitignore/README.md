## 파일 역할

실측 자료와 개발 산출물이 Git에 올라가지 않도록 제외합니다. 원본은 [.gitignore](../../../../.gitignore)입니다.

## 사용 순서

새 파일 추가 전 git status --short --ignored로 제외 여부를 확인하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

실측 이미지, measured_*.json, real_calibration.json, 캐시와 빌드 폴더를 제외합니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

제외 규칙은 이미 추적 중인 파일을 제거하지 않습니다. 비밀정보를 저장하지 마세요.
