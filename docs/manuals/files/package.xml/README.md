## 파일 역할

ROS 2 빌드 방식과 런타임 의존성을 선언합니다. 원본은 [package.xml](../../../../package.xml)입니다.

## 사용 순서

Jazzy 환경에서 의존성을 준비한 뒤 colcon build를 실행하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

ament_python, rclpy, cv_bridge와 ROS 메시지 패키지를 선언합니다.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

선언이 있다는 이유만으로 의존성이 설치되거나 장비가 검증되지는 않습니다.
