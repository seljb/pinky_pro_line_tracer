## 파일 역할

실물 실험 조건과 결과를 기록할 CSV 헤더를 제공합니다. 원본은 [logs/experiment_template.csv](../../../../../logs/experiment_template.csv)입니다.

## 사용 순서

원본은 유지하고 별도 CSV로 복사해 시험별 한 행을 기록하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

거리 mm, 각도 deg, 시간 s, 지연 ms 등 컬럼 이름의 단위를 따르세요.

## 확인 방법

파일을 읽고 위 목적·경로와 일치하는지 확인합니다. 실행을 요구하지 않는 문서·설정 파일은 단독 실행하지 않습니다.

## 오류와 주의사항

합성 결과와 실물 데이터를 섞지 말고 미측정 값을 0으로 채우지 마세요.
