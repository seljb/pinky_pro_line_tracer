## 역할

오프라인 검증에 사용한 직접 의존성 버전을 고정합니다. [원본 파일](../../../../requirements-dev.txt)을 먼저 읽으세요.

## 사용 순서

저장소 루트에서 사용합니다. python -m pip install -r requirements-dev.txt

## 입력과 출력

설정·의존성 파일은 개발 도구가 읽습니다. Markdown 문서는 사용자가 읽고 작업 결과를 기록하기 위한 안내입니다. 파일 자체가 장치를 구동하지 않습니다.

## 완료 기준과 주의사항

가상환경에서 사용합니다. ROS 2 시스템 의존성이나 전이 의존성 전체를 잠그지는 않습니다.
