## 파일 역할

영상 픽셀과 바닥 실측 좌표의 대응점 형식을 보여줍니다. 원본은 [config/floor_pairs_example.json](../../../../../config/floor_pairs_example.json)입니다.

## 사용 순서

예시 숫자를 복사하지 말고 measured_floor_pairs.json에 실제 대응점을 기록하세요.

명령은 별도 표시가 없으면 저장소 루트 `pinky_pro_line_tracer/`에서 실행합니다. Python 명령은 의존성을 설치한 환경에서 실행합니다. ROS 명령은 Jazzy 환경을 source한 터미널에서 실행합니다.

## 입력과 출력

pixel_points와 ground_xy_m은 같은 순서입니다. 바닥 x는 전방, y는 좌측, 단위는 m입니다.

## 확인 방법

JSON을 읽을 수 있는지 확인한 뒤 보정 종류·해상도·단위를 검토합니다. JSON 문법 통과는 실물 보정 성공을 뜻하지 않습니다. 자세한 실행은 [루트 안내](../../../../../README.md)를 따르세요.

## 오류와 주의사항

내부 보정 적용 시 왜곡 보정된 영상 좌표를 사용합니다. 최소 4개 비공선 점이 필요합니다.
