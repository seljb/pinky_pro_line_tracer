## 역할

재생 도구 점검용 합성 AVI와 장면 종류 CSV를 만듭니다. [원본 파일](../../../../../scripts/make_synthetic_video.py)을 확인하세요.

## 사용 순서

python scripts/make_synthetic_video.py --output /tmp/pinky-fixture.avi

명령은 저장소 루트의 오프라인 가상환경에서 실행합니다. ROS 노드는 별도의 시스템 Jazzy 환경을 사용합니다.

## 입력과 출력

320×240, 기본 60프레임·10FPS의 직선·선 없음·밝기 변화·가지 후보 장면을 출력합니다.

## 완료 기준과 주의사항

실제 로봇 영상이 아닙니다. 기존 파일을 덮어쓰지 않으며 장면 이름을 실물 정확도로 보고하지 않습니다.
